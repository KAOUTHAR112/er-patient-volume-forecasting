# Résultats validés

Ce dossier contient les sorties de l’exécution complète réalisée avec le dataset fourni :

- `model_comparison.csv` : métriques de tous les modèles ;
- `timeseries_cv_summary.csv` : validation temporelle des modèles d’ensemble ;
- `future_forecast.csv` : prévision des 30 jours suivants ;
- `run_metadata.json` : paramètres et dimensions de l’exécution.

Le fichier patient brut et la série journalière agrégée ne sont pas inclus. Consultez `docs/RESULTS.md` pour l’interprétation.
