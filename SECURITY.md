# Politique de sécurité

Pour signaler une fuite de données ou un problème de confidentialité, n'ouvrez pas immédiatement une issue publique contenant les données concernées. Retirez d'abord le fichier du dépôt et de l'historique Git, puis contactez le propriétaire du dépôt par un canal privé.

Aucun secret, jeton, identifiant patient ou fichier hospitalier brut ne doit être commité.
