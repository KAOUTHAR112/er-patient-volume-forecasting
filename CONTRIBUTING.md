# Contribuer

1. Créez une branche depuis `main`.
2. Ne déposez aucune donnée patient brute.
3. Ajoutez ou mettez à jour les tests.
4. Exécutez `pytest -q`.
5. Décrivez clairement la modification dans la pull request.

Les nouveaux modèles doivent respecter le split chronologique et être comparés aux baselines existantes.
